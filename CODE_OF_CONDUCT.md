# Community code of conduct

WAM Privacy Wallet welcomes contributors of all experience levels. The project values technical accuracy, reproducibility, constructive disagreement and respectful discussion.

## Expected conduct

- Be courteous, patient and specific when giving feedback.
- Critique code and technical claims, not people; assume good faith while requiring evidence.
- Respect privacy, consent, contributor credit and intellectual-property rights.
- Report suspected security vulnerabilities privately under [SECURITY.md](SECURITY.md).
- State test scope and limitations precisely; do not claim production readiness without evidence.
- Do not spam, impersonate contributors, harass others, threaten, publish personal information, or promote deceptive financial claims.

## Enforcement

Repository maintainers may request edits, moderate comments, lock discussions, or restrict participation after considering severity and context. If a report concerns a maintainer, use another trusted project representative or GitHub's platform reporting processes. Avoid publishing sensitive information in public reports.

This policy applies in project-maintained GitHub issues, pull requests, discussions and other official project collaboration spaces.
